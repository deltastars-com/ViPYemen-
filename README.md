# ViP Yemen — منصة التوظيف والتسويق العقاري والإلكتروني والخدمات البرمجية

منصة يمنية شاملة متعددة الأقسام تربط أصحاب الأعمال والباحثين عن الفرص في اليمن،
بنظام مراجعة إدارية مضمون: كل طلب يصل أولاً إلى لوحة التحكم للمراجعة والتدقيق
والتعديل، ثم يُنشر بضغطة زر على واجهة المنصة.

## 🧱 التقنيات

| التقنية | الاستخدام |
|---------|-----------|
| React 19 + TypeScript + Vite 7 | واجهة المستخدم |
| Convex | الباك إند وقاعدة البيانات السحابية (تخزين الملفات والمزامنة اللحظية) |
| Tailwind CSS 4 | التصميم (ثيم ذهبي داكن — RTL) |
| Framer Motion | الحركات |
| vite-plugin-pwa | تطبيق ويب تقدمي (PWA) يعمل بدون إنترنت |

## 📱 أقسام المنصة

1. **التوظيف** — الباحثون عن عمل وأصحاب المنشآت (الاسم، الهاتف، العنوان، المنشأة، المهنة، الشروط)
2. **التسويق العقاري** — مالكو العقارات والمشترون (أرض/منزل/عمارة/فيلا/شقة) مع رفع الصور والربط بواتساب المنصة 00967711780999
3. **التسويق الإلكتروني** — بائعو ومشترو المنتجات مع تحقق من رقم الهاتف (OTP عبر واتساب) وإشارة "تم البيع"
4. **البرمجيات وتطوير التطبيقات** — طلبات المواقع والتطبيقات والأنظمة
5. **العروض الترويجية** — منشورة من لوحة التحكم بالصور والفيديوهات
6. **الإعلانات** — شريط إعلاني متحرك أعلى المنصة يُدار من لوحة التحكم (حالة/أولوية/جدولة) مع **نشر مجدول تلقائي** وانتهاء صلاحية عبر نظام الأتمتة
7. **الأتمتة** — كرون Convex كل 5 دقائق: نشر الإعلانات المجدولة، إيقاف المنتهية، أرشفة الطلبات المرفوضة القديمة، وإشعارات تلقائية
7. **المساعد الذكي** — محرك بحث معرفي شامل: بحث في المنشورات والعروض والإعلانات + بحث موسوعي عام (Wikipedia) — صفحة مستقلة لا تحجب التنقل
8. **الإصدارات** — تحميل التطبيقات والكود المصدري والوثائق
