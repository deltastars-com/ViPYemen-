# 🏛️ الأصل الرسمي للشعار

ضع هنا الصورة الرسمية للمنصة **كما هي** بالاسم:

```
assets/logo-official.png
```

الختم الذهبي الرسمي على الخلفية الكحلية (يفضَّل 1024×1024 · PNG · 8-bit · بلا تنسيد).

ثم نفّذ:

```bash
npm run icons:official
```

يُولِّد هذا الأمر **كل** أصول المنصة من هذه الصورة نفسها — بلا أي رسم برمجي
أو تغيير في المحتوى: أيقونات PWA، أيقونات أندرويد (عادية وتكيّفية ودائريّة)،
شاشات البداية (أندرويد + iOS)، أيقونة iOS، فافيكون، وجرافيك متجر جوجل،
مع تحقق فعلي بكسل-ببكسل بعد الكتابة.
